# Driver App

Driver-facing client. Handles auth/verification, online/offline toggle, incoming ride requests, navigation, trip status updates, and earnings.

## Setup

_To be filled in once the client stack is chosen (React Native, Flutter, web, etc.)._

## Key Screens

- Sign up / Login + document verification
- Online/offline toggle (home screen)
- Incoming ride request (accept/reject)
- Navigation to pickup / drop-off
- Trip status controls (arrived / start / complete)
- Earnings dashboard
- Trip history
- Rate rider
